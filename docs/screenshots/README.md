# Screenshots

Drop PNG/GIF captures of the rice here and reference them from the top-level
`README.md`, e.g.:

```markdown
![desktop](docs/screenshots/desktop.png)
```

Handy capture commands from a running Hyprland session:

```bash
~/.config/hypr/scripts/screenshot.sh full      # whole screen → ~/Pictures/Screenshots
~/.config/hypr/scripts/screenshot.sh region    # then edit in swappy
```
